# 🌅 定时问候插件

一个简单好用的 AstrBot 插件，让你的机器人每天定时发送 **早安、午好、晚安** 问候。

功能仅限问候。

---

## 🎯 功能特性

- ✅ **早安问候** - 每天早上固定时间发送
- ✅ **午好问候** - 每天中午固定时间发送
- ✅ **晚安问候** - 每天晚上固定时间发送
- ⏰ **时间自定义** - 每个问候的时间都可以自己改
- 💬 **内容自定义** - 每个问候可以写多条内容，每天随机选一条
- 📌 **多会话支持** - 可以同时发送到多个群/私聊
- ✅ **独立开关** - 每个问候可以单独启用/关闭

---

## 📥 安装方法

### 方法一：从插件市场安装（推荐）

1. 打开 AstrBot 的 **Web 管理面板**
2. 点击左侧菜单 **"插件市场"**
3. 搜索 **"定时问候"** 或 **"greeting"**
4. 点击 **安装** 按钮，等待安装完成
5. 安装完成后，在 **"已安装插件"** 页面可以看到它

### 方法二：从本地文件安装

1. 下载本仓库的压缩包（ZIP）
2. 解压后，将 `astrbot_plugin_greeting_bot` 文件夹复制到 AstrBot 的 `data/plugins/` 目录下
3. 重启 AstrBot，或在 WebUI 中点击 **重载插件**

## 🚀 快速开始

### 第一步：添加发送目标

插件安装好后，需要告诉它把问候发到哪里。

在你想让机器人发问候的 **群聊** 或 **私聊** 中，发送这条指令：

```
/greet_add
```

机器人会回复确认：

```
✅ 已将当前会话添加到问候列表！
现在共有 1 个目标会话
```

**重复上面的操作**，可以添加多个群或私聊。

### 第二步：自定义问候语和时间（可选）

打开 AstrBot 的 **Web 管理面板** → **插件** → 找到 **"定时问候"** → 点击 **配置** 按钮。

你会看到类似这样的配置界面：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 启用插件 | 总开关 | ✅ 开启 |
| 🌅 早安 → 启用 | 早安问候开关 | ✅ 开启 |
| 🌅 早安 → 发送时间 | HH:MM 格式 | 07:30 |
| 🌅 早安 → 问候语 | 多条列表，每天随机 | 3 条默认语 |
| ☀️ 午好 → ... | 同上 | 12:00 |
| 🌙 晚安 → ... | 同上 | 22:30 |

修改完后点击 **保存**，插件会自动生效。

### 第三步：测试一下

在任意会话中发送：

```
/greet_test
```

机器人会立即发送一条测试问候，帮你确认配置是否正确。

## 📖 指令列表

所有指令以 `/` 开头。

| 指令 | 说明 |
|------|------|
| `/greet_add` | 将当前会话添加到问候列表 |
| `/greet_remove` | 将当前会话从问候列表移除 |
| `/greet_list` | 查看当前所有配置和目标 |
| `/greet_test` | 发送一条测试问候 |

## ⚙️ 配置说明详解

### 时间格式

时间使用 **24 小时制**，格式为 `HH:MM`：

```
07:30  →  早上 7 点 30 分
12:00  →  中午 12 点
18:45  →  傍晚 6 点 45 分
23:59  →  午夜 11 点 59 分
```

### 问候语配置

每个问候类型可以配置 **多条** 问候语：

```json
{
  "messages": [
    "早安！新的一天开始啦！☀️",
    "早上好呀！今天也要加油哦～",
    "清晨的第一缕阳光送给你！"
  ]
}
```

每天到点时，插件会从列表中 **随机选一条** 发送，增加自然感。

### 推荐的问候语示例

**早安：**
```
早安！愿你今天充满正能量！💪
起床啦～太阳公公在叫你呢 ☀️
新的一天，新的开始，早安！
```

**午好：**
```
午饭时间到！记得好好吃饭哦 🍚
中午好～休息一下，下午继续加油！
吃饱饱，没烦恼～午好！
```

**晚安：**
```
夜深了，早点睡吧～晚安 🌙
祝你今晚做个甜甜的梦 ✨
晚安啦，明天见！
```

## ❓ 常见问题

### Q: 机器人到点了没发消息？

1. 检查插件总开关和对应问候的开关是否打开
2. 确认时间设置的格式正确（HH:MM）
3. 用 `/greet_list` 检查是否已经添加了目标会话
4. 确认 AstrBot 正在运行，网络正常
5. 检查 WebUI 的日志，看有没有报错

### Q: 怎么改发送时间？

打开 WebUI → 插件 → 定时问候 → 配置，找到对应问候类型的 `time` 字段修改即可。

### Q: 可以只发早安不发晚安吗？

可以。在配置中把不需要的问候类型的 **启用** 开关关掉就行。

### Q: 怎么删除某个群？

在那个群里发送 `/greet_remove` 即可。

### Q: 私聊也能发吗？

可以。在私聊中发送 `/greet_add` 就能把私聊也加进去。
